# Sports Proxy

ESPN CORS proxy for the Bandwagon Bootcamp app.

## Endpoints

- `GET /team/:sport/:league/:id` — Team info and record
- `GET /scoreboard/:sport/:league` — Recent scores
- `GET /standings/:sport/:league` — League standings
- `GET /` — Health check

## Deploy to Render

1. Connect this repo to render.com
2. Runtime: Node
3. Start command: `npm start`
4. Deploy
